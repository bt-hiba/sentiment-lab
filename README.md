# SentimentLab
## Features

### Time Series Analysis

This feature analyzes the evolution of sentiment over time using the Sentiment140 dataset.

It provides:
- Daily tweet counts.
- Daily positive and negative tweet counts.
- Daily positive and negative sentiment percentages.
- CSV export of daily sentiment statistics.

The generated results are saved in `data/processed/daily_sentiment.csv`.

The full dataset must be placed in `data/raw/` before running the analysis.
